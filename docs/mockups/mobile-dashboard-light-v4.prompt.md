# モバイル・ライトモード画面モック v4 生成指示

## 目的

v3を基に、現在地カードへ概算標高を追加したS-010ダッシュボードの画像モックを作る。

## 編集指示

- 現在地カードの「精度の目安 ±18m」と「取得 14:31」の間に「標高 約10m（概算）」を追加する。
- v3で確定した小杉ゴシック、日付と時計の同じ強調、潮の目安以降の最寄り駅・役所・医療機関という順序を維持する。
- 全カード、出典・プライバシー、保存データ削除、版表示が縦長画面内へ収まるよう、カード間隔と内側余白だけをわずかに調整する。
- 標高をGPS精密高度や防災用途の値として表現しない。

## 注記

標高はOpen-Meteo Weather API応答の例。実装では90m解像度の地形モデル由来の概算値として扱い、欠損時は標高行だけを非表示にする。
