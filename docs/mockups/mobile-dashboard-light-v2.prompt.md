# モバイル・ライトモード画面モック v2 生成指示

## 目的

承認済みのv1を基に、ブランド階層と現在日時を反映したS-010ダッシュボードの画像モックを作る。

## 参照画像

- `mobile-dashboard-light-v1.png`

## 編集指示

- 既存のスマートフォン画面、カード順、配色、角丸、余白、アイコン、表示内容は維持する。
- ヘッダーの大きな主タイトルを正確に「いまここインフォ」とする。
- 主タイトル直下に、小さく控えめな文字で正確に「© 2026 SIKUMI LAB」と表示する。
- その下に細い情報行を追加し、左に「2026年8月11日（火）」、右に現在時計「14:32」を表示する。
- 更新ボタン、共有ボタン、情報の最終更新表示「更新 14:32」は残し、現在時計と更新時刻が別物だと分かる配置にする。
- シクミラボを主タイトルへ前置しない。
- 日本語文字を崩さず、実用的なPWA画面モックとして描画する。

## 注記

画像内の日付・時刻・地点・数値はレイアウト確認用の例。実装ではJSTの現在日時を動的に表示する。
