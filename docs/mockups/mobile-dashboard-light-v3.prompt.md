# モバイル・ライトモード画面モック v3 生成指示

## 目的

v2を基に、日付の強調、カード順、小杉ゴシックを反映したS-010ダッシュボードの画像モックを作る。

## 参照画像

- `mobile-dashboard-light-v2.png`

## 編集指示

- 日付「2026年8月11日（火）」を時計「14:32」と同じ文字サイズ・太さにする。日付は左、時計は右を維持する。
- 「潮の目安」以降のカードを、最寄り駅、役所、医療機関の順に並べる。各カード内の内容は変更しない。
- 画面内の日本語・英数字すべてへ小杉ゴシック（Kosugi Gothic）の印象を適用する。
- 「いまここインフォ」「© 2026 SIKUMI LAB」「更新 14:32」など既存文字列、配色、アイコン、余白、角丸、カード内容、フッター、版表示は維持する。

## 注記

画像内の日付・時刻・地点・数値はレイアウト確認用の例。実装では小杉ゴシックをアプリへ同梱し、JSTの現在日時を動的に表示する。
