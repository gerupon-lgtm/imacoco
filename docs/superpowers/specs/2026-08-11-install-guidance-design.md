# PWAインストール案内 設計

## 目的

初回利用者が、対応端末で「いまここインフォ」をホーム画面またはアプリ一覧へ追加できることを理解し、その場で必要な操作へ進めるようにする。位置情報の初回説明、PWA起動、既存のライト／ダーク表示を損なわない。

## 採用方式

あとキューと同じ、端末状態に応じて内容を切り替える初回モーダル方式を採用する。

検討した方式は次の3つ。

1. 初回モーダル方式（採用）: 手順を省略せず説明でき、iOSとAndroid／PCで一貫する。初回画面と重ならないよう順序制御が必要。
2. 画面上部バナー方式: 表示を妨げにくいが、iOSの共有手順が長く、読み飛ばされやすい。
3. 情報パネル内の常設導線: 再確認しやすいが、初回利用者へ気付きを与えにくい。MVPでは追加しない。

## 表示条件

- iPhone／iPad相当端末では、ブラウザ表示中かつ未確認ならiOS案内を表示する。
- Android／PCでは、`beforeinstallprompt`を受け取った場合だけインストール案内を表示する。
- `display-mode: standalone`または`navigator.standalone === true`なら表示しない。
- 一度閉じる、またはインストール操作を完了した端末では再表示しない。
- 位置情報の初回説明が表示中ならインストール案内を待機し、初回説明を完了してダッシュボードへ移った後に表示する。
- ブラウザが非対応、イベントが来ない、保存が禁止されている場合も、ダッシュボードは通常どおり利用できる。

## 画面

共通モーダルは`role="dialog"`、`aria-modal="true"`、見出し参照を持つ。背景を覆う半透明オーバーレイと、既存カードに合わせた角丸・境界・配色を使う。外部アイコンは追加しない。

### iOS／iPadOS

- 見出し: 「いまここインフォをホーム画面に追加」
- 本文: 「iPhone・iPadではSafariで共有を開き、『ホーム画面に追加』を選んでください。」
- 補足: 「ホーム画面から、いまここインフォをすぐ開けるようになります。」
- 操作: 「わかりました」

### Android／PC

- 見出し: 「いまここインフォをインストール」
- 本文: 「ホーム画面やアプリ一覧から、いまここインフォをすぐ開けるようにします。」
- 補足: 「インストール後も、位置情報や表示データはこの端末だけに保存されます。」
- 操作: 「今はしない」「インストール」

インストール要求の結果が承認・辞退のどちらでも、この案内は表示済みとする。要求処理が例外になった場合はモーダルを閉じ、通常画面を維持する。

## 状態と保存

`AppSettings`へ`installPromptSeen: boolean`を追加し、既存保存データでは`false`を補完する。設定の全消去では他設定と同時に消えるため、次回条件を満たせば再表示できる。

ブラウザ状態は独立したPWAアダプターで管理する。

- `waiting`: Android／PCでイベント待ち
- `ios`: iOSブラウザ表示
- `installable`: `beforeinstallprompt`を保持
- `installed`: standaloneまたは`appinstalled`後

アダプターは状態取得、購読、インストール要求、イベント解除を提供し、UIはブラウザイベントの詳細型へ依存しない。

## 既存画面との関係

- 初回位置説明を最優先にし、モーダル同士を重ねない。
- 共有、情報、全消去の既存ダイアログが開いている間は新規表示しない。
- プレビューURLでは通常ブラウザ判定を使うが、E2Eはイベント注入で状態を制御する。
- 今回の同時修正として、医療注記を「緊急時は119」へ戻す。

## テスト

- 単体: iOS判定、iPadOS判定、standalone判定、`beforeinstallprompt`、`appinstalled`、表示済み設定の移行と全消去。
- コンポーネント: iOS文言、Android／PC操作、初回位置説明の優先、閉じた後の保存、インストール要求。
- E2E: iPhone相当初回、Android／PCのイベント発火、再訪非表示、standalone非表示、390pxライト／ダーク、キーボードフォーカス、既存初回GPSフロー。
- 回帰: `npm run check`と`npm run test:e2e`を完走し、Cloudflare Preview成功後にmainへマージする。

## 対象外

- iOSブラウザで共有シートを自動的に開くこと。
- 非対応ブラウザへ偽のインストールボタンを表示すること。
- インストール案内を常設設定へ追加すること。
- 独自のサーバー保存、解析、通知許可を追加すること。
